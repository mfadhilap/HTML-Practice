Inline Elements

<p>

It represents a paragraph. They are block level elements. They are used to write paras.

eg: <p> India is my country, all indians are my bros and sis </p>

<span>

here we can choose to select a part of line "span tag" by its ID and apply different styles and attributes to it

eg: This is to demonstrate how the <span id="paratag">span tag <span> works

<strong>

Its used to show content with prominence or high importance

eg: I am proficient in <strong>Python , Javascript</strong>

<em>

Its used to put strong emphasis on some text

eg: I was working on a project with a very close Deadline, so <em>we had to</em> put in more efforts. Mentor asked us to start working <em>the very next second!</em>

<b>

eg: Html has many tags like <b>p, span, strong, em, small, b, i, u, s, sup, sub, abbr, cite, q, code, kbd, samp, var, mark, del, ins, time, dfn</b>

<i>

eg: There's a spanish Quote that I follow, <i>"Al mal tiempo, buena cara"</i>. It translates to, <i>In difficult times, keep a positive attitiude.</i> This motivates me to push through hardships

<s>

It represents texts enclosed in it with a strikethrough line

eg : <s>There’s food upstairs</s> Nvm, Its finished!

<sup>

It is used to represent texts that have to be a superscript, Its purely for typographical reason

eg: A formula that has always been useful for me is a<sup>2</sup>+ b<sup>2</sup> = c<sup>2</sup> It's a misconception that maths is not useful after schooling

<sub>

It is used to represent texts that have to be a subscript, Its purely for typographical reason

eg: We should be drinking a lot of H<sub>2</sub>O in this scorching heat.

<cite>

It is used to mark the title of a creative work like books, blogs etc

eg: A book I'd suggest everyone to read is <cite>Rich Dad,Poor Dad</cite>,by Robert Kiyosaki and Sharon Lechter

<small>

It is used to represent small prints and side notes

eg: <small>Copyright © 2026 | mfad@vonnue.com</small>

<q>

It is to show that the text inside q tag is a quotation maybe cited from somewhere else, it will enclosed inside quotes

eg: When simran said Sorry, Raj replied <q cite="https://www.imdb.com/name/nm0451321/?ref_=ttqu_qu"> Never mind, Señorita, never mind .In big places ,such small things happen</q>

<code>

It is used to show that the text is a fragment of computer code

We use <code>print()</code> to print anything in python

<kbd>

It is used to represent user input from mouse, keyboard etc

eg : Press <kbd>Ctrl</kbd>+<kbd>A</kbd> to copy all content

<samp>

It is used to represent a sample output of a computer program

eg: If you add special characters or numbers, it will show <samp>Invalid Input </samp>

<var>

It is used to represent a variable in a mathematical expression

eg: You can calculate volume of cube by <var>s</var> × <var>s</var> × <var>s</var>

<mark>

It is used to highight texts. By default it will be highlighted in yellow color

eg: Today I saw a <mark>UFO</mark>

<del>

It is used to represent that the part of text enclosed in it has been removed from the document

eg: <del>This text has been deleted</del> This is the newer text

<ins>

It is used to represent that the part of text enclosed in it has been inserted into the document. It is the opposite of del tag

eg: <del>This text has been deleted</del> <ins>This is the newer text</ins>

<time>

It is used to represent time period. It helps in better search results

Bake the cake for <time datetime="PT40M">40 minutes</time>and then let it cool down

<dfn>

It represents a term to be defined and should be used in a complete definition statement

We use <dfn title="Cascading Style Sheet">CSS</dfn> to style webpages
